# 攻破城门

一个网页上的构筑卡牌下棋游戏。4 路 × 5 格的棋盘，双方各有一座城堡，把兵一格一格推进对面的城门。组一副 12 张牌的卡组，和电脑对战。

**现在是试玩阶段。** 打开就能玩，玩完请留一条反馈。

- 试玩和反馈：https://cuiyucheng0104-afk.github.io/breach-the-gate/
- 直接进游戏：https://cuiyucheng0104-afk.github.io/breach-the-gate/play/

## 有什么

- 六个阵营加中立，366 张牌，各有自己的玩法（圣盾、连击、方尖碑、暗影、成长、冻结……）。
- 自由对战：12 套预设卡组，也可以自己组牌，组牌界面会帮你看这副牌缺什么。电脑分四档难度：入门、普通、困难、大师。大师是电脑自己跟自己打了几十万局训练出来的（整回合组合搜索 + 局面价值网络），对困难约赢六成四。
- 卡牌联盟锦标赛：16 人瑞士轮，带两套卡组参赛，三胜出线，八强起淘汰赛；冠军开宝箱拿卫冕冠军 Q1 的整套中立卡组。三个种子选手（Q1、克劳德、GPT嗖）用大师电脑。
- 闯关：七个场地 35 关，进每个场地时选一套卡组，场地最后是首领，打赢获得首领牌。通关一个阵营场地得一枚徽章，集齐六枚才能进无主之地（四个小首领，然后是最终首领）。
- 棋盘上没有随机：每一步会发生什么，选牌时就画给你看。随机的只有抽牌——补牌和换牌都从牌库里随机来一张。

## 已知的不足

- 新手教学只有一关（两三分钟，教出兵、前进、前线、换牌、法术、冲门），冲锋拐弯和各阵营的机制还没有教。
- 手机横屏已适配，但还没在真机上试过；目前在电脑上体验最好。
- 设置页还没做；声音没有细调。
- 闯关的难度只用电脑模拟校准过。

## 在自己电脑上运行

不需要安装依赖，也不需要构建。

```bash
python3 tools/serve.py 8770
```

然后打开 `http://localhost:8770/board.html`。

规则自检：

```bash
node tools/chess_check.mjs
```

## 目录

| 文件 | 内容 |
|---|---|
| `chess.js` | 规则核心和电脑的打法 |
| `chess-net.js`、`assets/ai/` | 大师电脑（自由对战大师档、锦标赛种子选手）用的局面价值网络和它的权重 |
| `cup.js`、`cup-ui.js` | 锦标赛 |
| `chess-cards.js` | 全部卡牌 |
| `campaign.js` | 闯关的关卡数据和存档 |
| `tutorial.js` | 新手教学：一局照脚本走的对局 |
| `board3d.js` | 场景和特效（three.js，全部用代码画） |
| `board-pfx.js`、`ui-pfx.js` | 像素特效：什么场合放哪个特效的对照表，棋盘上和界面上的播放器（特效库在 `vendor/pixelfx`，MIT） |
| `chess-ui.js`、`style.css`、`motion.css` | 界面和动效 |
| `audio.js`、`sound.js` | 声音 |
| `tools/` | 自检、平衡、打包、画图标的脚本 |
| `tools/lab/` | 电脑训练和数值实验：组合普查、估值校准、预设调牌、网络训练和对打 |
| `pages/` | 试玩和反馈页 |
